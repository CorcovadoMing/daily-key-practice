# 弓弦的每日練習 🎻

一個專為大提琴日常練習與師生課堂設計的 **24 調音階抽籤網站**。

## 功能

- **完整 24 調**：12 個大調、12 個古典旋律小調；旋律小調上行升高第 6、7 級，下行恢復自然小調。
- **依調號篩選**：24 個調性預設全部啟用，可依升降記號分類選取或排除；「全部選取／全部取消」快速調整練習範圍。
- **自由抽選**：分別設定大調與小調要抽的數量，隨機抽出不重複的調性；候選不足時提醒調整。
- **視覺化大提琴指板**：C、G、D、A 四弦音位圖，標示音名與演奏順序，支援上行／下行及 1／2 個八度切換。
- **練習進度**：完成的調性可打勾、顯示完成比例、選擇是否顯示音階音名。
- **老師自訂指法**：記錄每個調性的上行、下行指法、換弦及換把註記。
- **課堂即時同步**：建立六位數房號或分享連結，師生共同同步調性篩選、抽籤數量、結果、進度與指法註記，並顯示目前連線數。
- **個人練習紀錄**：在目前瀏覽器保留當日練習和近期歷史。
- **版本識別**：網頁頁尾顯示日期與流水號，例如 `v2026.11.06-001`。

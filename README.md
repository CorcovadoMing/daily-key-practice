# 弓弦的每日練習 🎻

一個專為大提琴日常練習與師生課堂設計的 **24 調音階抽籤網站**。

## 功能

- **完整 24 調**：12 個大調、12 個古典旋律小調；旋律小調上行升高第 6、7 級，下行恢復自然小調。
- **依調號篩選**：24 個調性預設全部啟用，可依升降記號分類選取或排除；「全部選取／全部取消」快速調整練習範圍。
- **自由抽選**：分別設定大調與小調要抽的數量，隨機抽出不重複的調性；候選不足時提醒調整。
- **彩色大提琴指板**：依半把位、第一把位、延伸把位、換把位與高把位使用不同顏色，另有簡潔圖例，不顯示換把箭頭或起點圈；空弦採空心圓。每個大調採用按調性編排的兩個八度參考指法，旋律小調則採分組參考指型；均可由老師修改，支援上／下行及 1／2 個八度。
- **練習進度**：完成的調性可打勾並顯示完成比例。
- **老師自訂指法**：開啟互動指板，將音符拖到同音高的其他弦位，或在手機上點選音符再選位置；支援上行／下行、左手 1～4 指號與換把位，並保留補充文字備註。
- **課堂即時同步**：直接在頁面顯示六位數房號，也能分享連結；師生共同同步調性篩選、抽籤數量、結果、進度與指法註記，並顯示目前連線數。
- **個人練習紀錄**：在目前瀏覽器保留每日練習歷史，可逐日刪除不需要的紀錄；保留的紀錄不再因超過 90 天而自動清除。
- **版本識別**：網頁頁尾顯示日期與流水號，例如 `v2026.11.06-005`。
